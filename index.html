The data

768 women aged 21 and over, each with 8 measurements: pregnancies, glucose, blood pressure, skin thickness, insulin, BMI, family history score and age. About 35% tested positive for diabetes.

A hidden problem: zeros that mean "missing"

Blood pressure of 0 is impossible. In this dataset, a 0 stands for a missing value. The notebook converts these to missing and fills them using the median, inside the model pipeline so the test set stays untouched.

Counts of impossible zeros in the original data: run the notebook's data quality step to see yours.

Method

  1. Clean. Treat impossible zeros as missing and impute with the median.
  2. Explore. Compare distributions by outcome and check correlations.
  3. Split. 80% train, 20% test, stratified.
  4. Compare. Five-fold cross-validation on four models, judged on ROC AUC and recall.
  5. Tune. Grid search on logistic regression.
  6. Check calibration. Does 70% predicted risk mean about 70% actually have diabetes?
  7. Choose a threshold. Trade missed cases against false alarms.
  8. Explain. Permutation importance and model coefficients.

Limitations

This is an educational project, not a medical tool. The data covers a single population, many values were imputed, and nothing has been validated externally. Models can perform worse for groups missing from the training data.
